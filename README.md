# Student Details Program

## Description
This is a simple Java program that demonstrates the use of:
- Class and Object
- Constructor
- Instance Variables
- Methods

## Program
The program creates a Student1 class with two variables:
- name – stores the student's name.
- age – stores the student's age.

A constructor initializes the student details, and the display() method prints them.

## Source Code
File name: Student1.java

## How to Run

### Step 1: Compile
```bash
javac Student1.java
```

### Step 2: Run
```bash
java Main
```
